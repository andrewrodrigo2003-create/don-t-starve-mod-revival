Metals and More Reforged — Changelog
=====================================

Version 2.9.5 — test build (2026-11-12)
---------------------------------------

Forge and smelting
- Validate the exact ingredient receipt before consuming any input.
- Preserve and retry refunds when an interrupted batch cannot return every item immediately.
- Keep the forge locked while a refund is pending; persist the pending state across save/load.
- Preserve ready output if spawning/harvesting fails, and retry without duplicating delivered items.
- Recover materials safely when the forge is hammered during processing.
- Retry incomplete vanilla/craftbook recipe migration passes instead of marking partial work complete.
- Keep the forge preview client-side for responsiveness while the server remains authoritative for the final result.
- Display predicted product name over its image and quantity in the lower-right of the image.

Compatibility and performance
- Remove the legacy global Lucy projectile hook; keep normal Lucy/axe behavior and the mod's melee/AOE weapon features.
- Wrap stategraph/combat callbacks while preserving arguments, return values and cleanup.
- Preserve fallback behavior for actions and recipes modified by other mods.
- Reduce repeated screen-size table allocation in the minimap update path.
- Register custom metal inventory atlases for crafting and preview UI.

Mining and storage
- Keep the additive extra-drop mode and its source-specific controls.
- Restore the optional 25-slot metal storage chest recipe (default: On). Its filter accepts registered smelting ingredients and products only.
- The chest does not yet query nearby containers or automatically feed the forge.

Balance and scope
- No smelting recipe costs, output quantities, weapon damage values or progression costs were changed in this test build.
- Hydrated/Dehydrated, Better Lucy, Uncompromising Mode and other mods were not edited.
- The metallurgy reference book, reversible material deconstruction, final recipe/station matrix, nearby-storage query, W.O.B.O.T./W.I.N.bot forge automation and KTEX icon conversion remain in development.

Verification
- Lua 5.1 parsing, regression harnesses, behavioral simulator contracts, custom asset references and install-package content checks passed in GitHub Actions for the 2.9.5 test build.
- This is not a claim of in-game, multiplayer, save migration or Uncompromising Mode Public Beta compatibility. Test in the dedicated world before using in a main world.
